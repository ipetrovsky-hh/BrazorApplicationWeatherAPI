Данный проект # BrazorApplicationWeatherAPI
является демонстрацией работы приложения Brazor
Особенности:
1) Используется Api получения прогноза погоды почасово.
2) в проложении настроен HttpClient на Localhost
3) В приложении настроен Swagger
4) в приложении есть контроллер
5) настроена маршрутизация для контроллера
6) основа проекта https://github.com/ipetrovsky-hh/Public-modification-for-weather-api
7) не делал замену record на класс.
8) вызов контроллера доступно по ссылке
9) Данные для страницы берутся из сети интернет, файлы json не используются
10) авторизация, идентификация не делал.
